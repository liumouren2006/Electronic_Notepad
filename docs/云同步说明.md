# 墨记 MoJi · 云同步说明（PC / Android）

云同步是**可选功能**。不登录仍然可以完整使用本地记事；客户端启动时不会强制弹出登录界面。

## 服务地址

- 服务：`http://dsbot.taild07bbe.ts.net:8789`
- 备用（无 MagicDNS）：`http://100.116.113.16:8789`
- 网页登录：`/login`；注册：`/register`；
- 管理员后台：`/admin/login`
- 健康检查：`/api/health`

只监听阿里云 ECS 的 Tailscale 地址 `100.116.113.16:8789`，不对公网开放。
PC 需安装并登录 Tailscale（与手机同一账号）；手机需在同一 tailnet。
管理员邮箱/密码由部署者保存，不在公开仓库中。

## 客户端流程

```
登录（可选）
  │
  ├─ 启动时：GET /api/sync/meta
  │     ├─ 云端版本 == 上次版本，且本地无改动 → 不联网同步
  │     ├─ 云端新增/更新 >= max(4, 本地数×25%) 或附件差 >= 5 → 弹窗询问
  │     └─ 小变化 → 自动同步
  │
  ├─ GET /api/sync/download      下载云端 .mjnote
  ├─ 本地合并（同 id 取 updated_at 较新；标题+创建时间去重）
  ├─ 导出新的 .mjnote（包含附件）
  └─ POST /api/sync/upload       带 X-Moji-Base-Version，409 时重新拉取重试
```

- 快照格式与 PC `.mjnote` 一致（manifest version 2），附件按 `files/<event-id>/` 打包。
- 删除同步：客户端记录上次同步的 ID 集合，删除后上传时带 `X-Moji-Deleted`；
  服务端保存删除时间墓碑（`tombstones`），其他设备拉取时移除本地未更新的同名记录，
  避免“已删除记录复活”。
- 云同步范围：事项、Markdown 备注、页面 `page_layout` 墨迹、附件、标签、提醒、铃声路径等事件字段。
- 本地 `config.json` 中的窗口/主题/Logo 属于本机设置，不上传。
- 每个设备保留自己的登录令牌；退出登录只清令牌，不删除本地数据。
- 每事项自定义铃声的**音频文件**目前不随 `.mjnote` 上传，换设备后会回退默认铃声。

## 本地 SSH 隧道（不依赖 PC 版 Tailscale）

和 dsBot 管理面板一样，可以用 SSH 本地端口转发：

- 双击 `D:\程序设计\moji-cloud\启动云同步隧道.bat`，保持窗口打开（可最小化）；断开会自动重连。
- 本地服务：`http://127.0.0.1:18789`
- 本地后台：`http://127.0.0.1:18789/admin/login`
- 本地网页登录：`http://127.0.0.1:18789/login`
- 停止：`停止云同步隧道.bat`
- 专用隧道密钥 `.ssh/moji_tunnel` 在服务器 `authorized_keys` 中被限制为
  `command=/bin/false,no-pty,permitopen=100.116.113.16:8789`，不能拿来登录 shell。

一键启动墨记并切到本地隧道地址：

`D:\程序设计\moji-cloud\启动云同步隧道并打开墨记.bat`
（会把 `%USERPROFILE%\.moji\config.json` 的 `cloud_server` 改为
`http://127.0.0.1:18789` 并打开新版墨记；切回 Tailscale 用
`恢复云同步为Tailscale直连.bat`。）

手机端没有稳定的 SSH 客户端常驻方案，仍建议走 Tailscale MagicDNS。

## PC 端

- 侧栏「云同步」或「文件 → 云同步…」打开账号窗口。
- 首次使用：填写服务器地址、邮箱、密码；可直接注册。
- 登录后显示邮箱、服务器、上次同步时间与云端版本。
- 启动 1.8 秒后自动检查；大变化弹窗，小变化静默合并并提示。
- 配置键（`config.json`，仅本机）：`cloud_server`、`cloud_email`、`cloud_token`、
  `cloud_last_version`、`cloud_last_sync_at`、`cloud_skip_version`。
- 依赖 Qt6 Network；安装包已带 `Qt6Network.dll`。

## Android 端

- 首页右上角云图标或「设置 → 云同步」进入账号页。
- 与 PC 相同的登录/注册、合并与大变化提示逻辑；令牌存 SharedPreferences。
- 服务地址可在登录页修改（MagicDNS 不可用时填 Tailscale IP）。
- 目前允许明文 HTTP，但只在 Tailscale WireGuard 内网传输；不要把 8789 暴露到公网。

## 服务端管理

后台功能：用户列表、同步版本/事件/附件/占用、重置密码、启用/停用、删除用户、修改管理员密码。
部署、API、备份与安全细节见 `D:\程序设计\moji-cloud\README.md`。

建议：
1. 首次登录后台后修改管理员密码；
2. 定期备份 `/var/lib/moji-cloud`；
3. 不要把 8789 加入阿里云安全组公网放行；
4. 如果更换 Tailscale 节点/IP，更新 `/etc/moji-cloud.env` 和客户端服务器地址。
